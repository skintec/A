# Paquete de marca Muralia para Claude Code

Contenido:
- `BRAND.md` — manual de marca resumido (posicionamiento, logo, color, tipografía, tono, reglas).
- `tokens/colors.json` y `tokens/tokens.css` — paleta y variables de diseño.
- `logo/` — logo original y variantes transparentes (grafito, terracota, papel, negro), favicon 512 y apple-touch-icon.

Cómo usarlo: copia esta carpeta al repo (por ejemplo `/brand`) y pide a Claude Code que lea `BRAND.md` y `tokens/` antes de trabajar.
Notas: los PDF de manual y los SVG de estampados/banners no están aquí; están en la carpeta de Drive indicada en BRAND.md sección 11.
